Read

js/foo_uie_jsplitter.js:3411
Read(buffer, offset, count)

Reads bytes into an existing Uint8Array without allocating a new buffer.
If offset is omitted, reading starts at index 0. If count is omitted, bytes are read up to the end of the buffer.
An explicitly supplied offset + count must fit inside the buffer.

Parameters

NameTypeDescription
bufferUint8Array

Destination buffer.

offset = 0optionalnumber

countoptionalnumber

Maximum number of bytes to read. Defaults to the remaining buffer size.
