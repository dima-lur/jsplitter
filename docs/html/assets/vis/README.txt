JSplitter Visualization API illustrations
========================================

The six PNG illustrations accompany the corresponding visualization sections:
  waveform.png
  spectrum.png
  peak-meter.png
  vu-meter.png
  spectrogram.png
  vectorscope.png

They illustrate the visualizations; their appearance does not define API defaults.
The article references them as assets/vis/<filename>. The documentation generator
copies this source directory into component/docs/html/assets/vis when rebuilding.

pipeline.svg illustrates source rendering, feedback history, compositing and
screen-only post-processing.
